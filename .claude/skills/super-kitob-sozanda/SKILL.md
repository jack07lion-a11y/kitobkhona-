# Super kitob sozanda (Китобхонаи тоҷикӣ)

Корбар: Ҷасурбек (iPhone). Забон: тоҷикии софи адабӣ, содда, ҳар қадам кӯтоҳ. Бе ҳарфи ӯзбекӣ/русӣ. Ҷавоб: тоҷикӣ.
Лоиҳа: GitHub `jack07lion-a11y/kitobkhona-`, сервер: Supabase (лоиҳаи «Kitobkhona»). Қоидаҳои лоиҳа: `CLAUDE.md`. Ҳуқуқи китобҳо: `docs/kitob-huquq.md`.

## Қоидаи асосӣ
Ҳар китоб (ё чанд китоб) омад → ҳамеша ду қисм:
1. **ҚАДАМИ 1 — PDF**: матн + расмҳо + ҳуқуқ ба PDF, фиристодан ба Ҷасурбек (`SendUserFile`). Ба сервер ҲЕҶ чиз намегузорем.
2. **ҚАДАМИ 2 — Китобхона**: фақат баъди ҷавоби «ҳа» (ё «бошла/гузор»). Китоб ПИНҲОН (`published=false`) мегузорем. Пинҳонро НАМОЁН кардан — фақат бо иҷозати алоҳида.

Дар охири ҳар ҷавоб ЯК қадами навбатиро нависед (масалан: «Ба Китобхона мегузорам (пинҳон)? ҳа/не»). Саволи дигар надеҳ.

## Қадами 1: PDF
Талаб: `poppler-utils`, `tesseract-ocr`, `tesseract-ocr-tgk`, `python3` бо `Pillow`, `numpy`, `scipy`, `reportlab` (агар нест: `apt-get update && apt-get install -y tesseract-ocr tesseract-ocr-tgk` ва `pip install scipy`).
Скриптҳо: `.claude/skills/super-kitob-sozanda/scripts/` (бо `python3 -I` кор кунед, дар папкаи корӣ, на дар папкаи файлҳои ғайриэътимод).

1. **Омӯз**: `pdfinfo`, `pdftotext` — агар матн ҳаст, OCR лозим нест. Саҳифаҳои аввал, мундариҷа ва охирро бо чашм бинед (расм). Ҳар китобе, ки ошкоро пурра нест (скан нопурра), ҳамонро ба Ҷасурбек бигӯед.
2. **OCR**: `scripts/ocr.sh КИТОБ.pdf кор/ 200 tgk` → `кор/img`, `кор/tsv`. Форматҳои дигар: `tools/kitob_convert.py` (docx/epub/fb2/txt) — матн аллакай ҳаст.
3. **Сохтор**: сарлавҳаҳо (ҳарфи калон, марказ), ҳарфи калони аввал (drop cap: ҳарфи аввалро аз контекст барқарор кунед), сархат (дар скан ё сатри нав ё чуқури чап), шеър (чуқури калон) ва шарҳҳои поёни саҳифа (`bk.py`; `flow.py` барои матни бидуни сарлавҳа). Саҳифаи рақам, сарлавҳаи такрорӣ, ҳошияи ороишӣ — партофта мешавад.
4. **Расмҳо**: `scripts/pics.py кор/ расм/` — қуттиҳои расмро меёбад; ҲАМЕША санҷед (contact sheet), нодурустро дастӣ ислоҳ кунед. Муқова: саҳифаи 1 бо `pdftoppm -r 110`.
5. **Тозакунӣ**: `clean.py` + `sus.py` (калимаи шубҳанок). Матнро ҲЕҶ ГОҲ аз худ «тузатма»: фақат хатои равшани OCR (бо расм муқоиса) ислоҳ шавад ва дар ҳисобот гӯед. Матне, ки OCR нахонд (дар атрофи расм), аз расм бо чашм хонда шавад.
6. **PDF**: `spec.json` созед (формат дар сарлавҳаи `scripts/mkpdf.py`) → `python3 -I scripts/mkpdf.py spec.json китоб.pdf`. Ҳар афсона/боб ҷудо, мундариҷа, расмҳо дар ҷойи худ, дар охир саҳифаи «Маълумоти китоб ва ҳуқуқ».
7. **Санҷиш**: саҳифаҳои аввал/миёна/охирро бо расм бинед (муқова ва сарлавҳа ба як саҳифа ҷо шавад, матн нашиканад). Расмҳоро ҳам дар zip гузоред.
8. **Фиристед**: `SendUserFile` — PDF-ҳо + zip-и расмҳо. Хулоса КӮТОҳ: чанд боб/саҳифа, сифати OCR, ҳуқуқ (3 сатр). Охир: қадами навбатӣ.

### Ҳуқуқ (ҳамеша аз худи китоб гиред, ҳеҷ чиз аз худ насозед)
Аз саҳифаҳои шиносномавии китоб (пушти сарлавҳа, охири китоб): муаллиф, тарҷумон, таҳриргар, рассом, нашриёт, шаҳр, сол, ISBN, адади нашр, ©, санаи чоп, суроғаи нашриёт, «бо дастгирии…». Қоидаҳо:
- Асли қадимӣ (Фирдавсӣ, Румӣ…) мулки умум; тарҷума/баргардони насрӣ/таҳрир/расм/нашр — ҳимоя мешавад → `pending`.
- Асари муаллифи имрӯза (© бо сол) → `pending`, ҳатман розигии хаттӣ.
- Афсонаи халқӣ (мулки умум) → `public_domain`, вале расмҳои нашр — алоҳида (тавсия: расмро нагиред).
- Муҳлати ҳимоя: умри муаллиф + тақрибан 70 сол (бо юрист санҷед; санаҳои марг аз худ ихтироъ накунед).
- «Бо дастгирии Президент» ҳуқуқ намедиҳад.
- Ҳолати ночаспон: `pending`. Барои ҳар китоб навиштед: `rights_status`, `rights_holder`, `source`, `edition`, `translator`, `license_note`.
Ҳар китоби нав ба `docs/kitob-huquq.md` илова шавад (commit + push ба шохаи кории худ).

## Қадами 2: ба Китобхона (ПИНҲОН)
Фақат баъди «ҳа». Жанр: `kids` (кӯдакон) ё аз рӯйхат: fiction, poetry, classic, science, history, religion, kids, text, exam, self, bio (аз Ҷасурбек пурсед, агар равшан набошад).
1. `python3 -I scripts/mkpayload.py spec1.json spec2.json …` → `payload.json`, `tok.txt`, ҳэши токен (spec: `slug`, `author`, `category`, `col`, `rights`).
2. Supabase MCP: `list_projects` (лоиҳаи «Kitobkhona»). `scripts/edge_import.ts`-ро бо ҳэши токен `deploy_edge_function` кунед (`name: tmp-import-books`, `verify_jwt: false`).
3. `curl -X POST https://<ref>.supabase.co/functions/v1/tmp-import-books -H "x-import-token: $(cat tok.txt)" -H "content-type: application/json" --data-binary @payload.json` — ҳар китоб `err:null` бошад.
4. ДАРҲОЛ функсияро `Deno.serve(()=>new Response("gone",{status:410}))` ва `verify_jwt:true` кунед. Токенро дар чат нанависед.
5. Санҷиш бо `execute_sql`: `select t,published,rights_status from books where slug in (...)` — `published=false`, файли матн дар Storage ҳаст.
6. Хабар: «пинҳон гузошта шуд», рӯйхат, ҳуқуқ, ва қадами навбатӣ: муқоваро гузоред, баъд «намоён кун».
Муқова: Ҷасурбек худаш мегузорад (Идоракунӣ → Китобҳо → Таҳрир → Муқова) ё расм бифиристад; бо `tools/cover_brand.py` нишон гузоред (қоидаҳо: `docs/muqova.md`).
Китоби мавҷуда (ҳамон `slug`) навсозӣ мешавад, такрор не.

## «Намоён кун»
Фақат бо фармони ошкоро: `update books set published=true where slug in (...)` ва `?v=ММДДЧЧММ` ссилкаи сайт: https://jack07lion-a11y.github.io/kitobkhona-/ . Пеш аз намоён кардан бигӯед: ҳуқуқ `pending` аст, розигӣ ҳаст?

## Қоидаҳои бехатарӣ
- `service_role`, паролҳо, токен — ҳеҷ гоҳ дар чат ё репо. Функсияи муваққатӣ баъд аз кор «410» мешавад.
