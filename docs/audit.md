# Аудити лоиҳа (2026-11-14)

Мақсад: аз боло то поён санҷида, ҳар чӣ худамон ислоҳ карда метавонем, ислоҳ кунем. Ин ҳуҷҷат — натиҷа ва қоидаҳои нигоҳдорӣ.

## Чӣ санҷида шуд
| Соҳа | Усул | Натиҷа |
|---|---|---|
| Хатои JS | ESLint (`no-undef`, `no-redeclare`, `no-unreachable`…) бар index.html-и сохта | 0 хатои ҷиддӣ; коди мурда (`updBanner`) нест карда шуд |
| Хатои вақти иҷро | `tests/crawl.js`: ҳамаи саҳифаҳо + 26 варақ × 3 нақш × забонҳо × андозаҳо (320/390) | 0 хато |
| Тарҷума | сатрҳои интерфейс бар ҷадвали `rows.json` | омехтаи ду забон (мис. «Errors ва пешниҳодҳо») ислоҳ; 70 сатри нав |
| Матни тоҷикӣ | Ҷустуҷӯи ҳарфҳо/калимаҳои узбекӣ ва русӣ | «Китоб ясаш» → «Сохтани китоб», «Ўрнатиш» → «Насб кардан», «Воронка» → «Роҳи корбар» |
| XSS | Ҷустуҷӯи `${…}` бе `escH` | ном/муаллиф/тавсиф/номи боб дар 10 ҷой ҳоло escape мешавад; `esc()` ҳоло & < > " -ро мегирад |
| Расм/муқова | Хондани кор | роҳи ASCII, нақшаи худкор агар расм кушода нашавад |
| Android | Манифест, WebView | ягона мушкил: хости GitHub Pages барои ҳамаи репозиторийҳо — ҳоло танҳо `/kitobkhona-` |
| Supabase | `get_advisors` (бехатарӣ + суръат), RLS, сиёсатҳо, функсияҳо | 4 ислоҳ татбиқ шуд (`docs/sql-audit.sql`); боқимонда — қасдан |
| Экрани танг (320px) | кроул | ҷадвали омор, забони русии «Танзимоти хондан», майдони ҷустуҷӯ |
| Хотира/гӯшкунакҳо | AST: `addEventListener`/`setInterval` дар функсияҳо, `localStorage` бе try | як ҷои нотамом (хабарҳо) ислоҳ шуд |

## Қасдан тағйир намедиҳем
- Ҷадвалҳои бе сиёсат (RLS ҳаст, сиёсат не): танҳо RPC-и SECURITY DEFINER бо санҷиши ҳуқуқ.
- 40 RPC-и «authenticated метавонад иҷро кунад»: ҳар кадом дар дохил `is_admin/has_perm/auth.uid` месанҷад ва хато меандозад.
- «Leaked password protection»: барнома рамз надорад.
- Чархи китобҳои «Охирин хондаам» дар 320px аз экран мебарояд — ин ҳаракати уфуқӣ аст (қасдан).

## Қоидаҳо барои оянда
1. Ҳар матни нав — тоҷикии соф + сатр дар `src/features/i18n/rows.json`. Сатри кӯтоҳ (≤12 ҳарф) — бо `"x"` дар сутуни 5 (фақат мувофиқати пурра).
   Ҷумлаи дароз бе сатри пурра бетағйир мемонад (на омехта).
2. Матни корбар/сервер дар HTML — ҳатман `escH(...)`.
3. `bindXxx($$)` ва `bindScr`-монанд ҷойҳо чанд бор даъват мешаванд: гӯшкунакро бо `__bound` як бор гузоред.
4. Пеш аз merge: `node tests/run.js` ва `node tests/crawl.js`.
