# Китобхона — давом эттириш учун

Янги чатга шу файлни ташланг ва ёзинг: «Шу лойиҳани давом эттир».

**Лойиҳа:** Китобхона — тоҷикча электрон кутубхона (асосийси китоб, қўшимчаси аудио). Аввал PWA, кейин APK. Намуна: Mutolaa, лекин ундан яхшироқ.
**Фойдаланувчи:** Жасурбек, iPhone. Ўзбекча кирилл, содда сўзлар, битта-битта қадам, қисқа натижа. Қарорни ўзи қабул қилади.

**Ҳозирги иш — ҳақиқий рўйхатдан ўтиш:**
- v19 дан бошлаб кириш почтага келадиган 6 хонали код орқали (Supabase). `SB_URL`/`SB_KEY` бўш бўлса намуна режими.
- Фойдаланувчидан кутилмоқда:
  1. Supabase лойиҳаси (kitobkhona, Frankfurt) очилгандан кейин **Project URL** ва **anon** калит. service_role калит ва паролни ҳеч қачон сўраманг.
  2. Почта шаблонига `{{ .Token }}` қўшиш.
  3. GitHub'да очиқ (public) «kitobkhona» репозиторийси ва GitHub Pages.
- Кейин: Google ва Telegram орқали кириш.

**Очиқ саволлар:** валюта номи (Хирад/Чисто/Ганҷ), тақдимотдаги сўраладиган сумма, асосчилар ҳақида маълумот ва суратлар.
