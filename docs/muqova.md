# Муқоваи китоб: нишонҳои Китобхона ва силсила

Асбоб: `tools/cover_brand.py` (намунаи «A», тасдиқи Ҷасурбек, ноябри 2026).

- **Боло:** логотипи хурди Китобхона бо ном (бе лавҳа). Андоза ҳамеша як хел.
- **Поён:** лавҳаи сабзи торик: нишони силсила (ситораи ҳашт гӯша, китоби кушода, ситорачаи афсонавӣ) ва матни ду сатра. Пешфарз: «Афсонаҳои халқи тоҷик».

## Қоидаҳо (Ҷасурбек гуфт)
1. Нишони поён («Афсонаҳои халқи тоҷик») ҳамеша бо ҳамин шакл мемонад. Агар китоби дигари ҳамин силсила бошад, ҳамин нишон мегузорем. Агар силсилаи дигар бошад, `--series "Ном"` (нишону шакл як хел, фақат матн).
2. Логотипи боло (Китобхона) ба ҲАМАИ китобҳо гузошта намешавад. Ба кадом китоб гузоштан — Ҷасурбек мегӯяд. Дар дигар китобҳо `--no-logo`.
3. Фармони «ном/тег гузор»-и Ҷасурбек (ном ё теги дигар) бошад, ҳамин андозаро нигоҳ дор.

## Истифода
```
python3 tools/cover_brand.py муқова.jpg натиҷа.jpg                 # ҳарду нишон
python3 tools/cover_brand.py муқова.jpg натиҷа.jpg --no-logo       # танҳо нишони силсила
python3 tools/cover_brand.py муқова.jpg натиҷа.jpg --series "Ном"  # силсилаи дигар
python3 tools/cover_brand.py муқова.jpg натиҷа.jpg --no-series     # танҳо логотипи боло
```
Муқоваи ворид: беҳтарин 700x1050 (2:3). Натиҷа JPEG.

## Ба сервер гузоштан
Муқова дар Supabase Storage (`books/<slug>/cover-<вақт>.jpg`), роҳаш дар `books.cover_path`. Роҳи оддӣ: Ҳисоб → Идоракунӣ → Китобҳо → Таҳрир → «Муқова (расм)». Ҷамъ: тавассути функсияи муваққатии Edge Function (калиди сервер фақат дар сервер, дар чат не).

## Муқоваҳои афсонаҳо
Расмҳо бо ChatGPT сохта шуданд (бе ҳарф, 1024x1536), номи файл = `slug` (масалан `afsona-vodareg.jpg`), баъд ба 700 px хурд ва бо `cover_brand.py` нишон гирифтанд.
