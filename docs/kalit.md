# Калити имзои APK

APK-ро бо **як калит** имзо мекунем. Калит гум шавад, иловаро дар телефонҳои мавҷуда навсозӣ карда намешавад ва ба Play Market баромадан мумкин нест.

## Чӣ дар куҷост
- `apk/ks.enc`: калит, **рамзгузоришуда** (AES-256, 600 000 такрор). Дар репозиторий меистад ва ба нусхаи дувум низ мерасад.
- **Парол**: GitHub → Settings → Secrets and variables → Actions → `KS_PASS`. Аз Secrets хондан мумкин нест, фақат навиштан. **Парол ҳам дар коғаз, ҳам дар ҷои хавфсиз (Google Drive/парол-менеҷер) нигоҳ дошта шавад.** Бе парол калит кушода намешавад.
- Парол дар репозиторий ва чат навишта намешавад.

## Парол
Камаш 20 ҳарф, тасодуфӣ (масалан 5 калимаи тасодуфӣ + рақамҳо). Хостан осон набошад.

## Якум маротиба сохтан
1. GitHub → Settings → Secrets → Actions → New repository secret: `KS_PASS` = пароли худатон.
2. Actions → «Калит (як маротиба)» → Run workflow.
3. Он `apk/ks.enc`-ро месозад ва ба `main` мефиристад. Баъд APK-и нав бо калити нав сохта мешавад.
4. Ҳамаи телефонҳо APK-ро як маротиба нест карда, аз нав насб мекунанд (имзо иваз шуд).

## Бозёфт (агар GitHub гум шавад)
Нусхаи репозиторий (GitLab/Codeberg) + `KS_PASS` дар даст бошад: `openssl enc -d -aes-256-cbc -pbkdf2 -iter 600000 -in apk/ks.enc -out kitobkhona.jks` (парол пурсида мешавад).
