# Китоб қўшиш: бир йўл, ҳар қандай формат

Мақсад: китоб қандай шаклда бўлмасин (Word, PDF, EPUB, FB2, TXT), уни **битта шаклга** (zip) келтирамиз, кейин иловага юклаймиз.

## 1. Китобни zip'га айлантириш
Конвертер: `tools/kitob_convert.py`

```
python3 tools/kitob_convert.py КИТОБ.docx --title "Ном" --author "Муаллиф" --category fiction
```

| Формат | Нима ёрдам беради |
|---|---|
| **Word (.docx)** | «Заголовок 1» = қисм, «Заголовок 2» = боб. Бир абзацдаги сатр-сатр (Shift+Enter) матн = шеър |
| **EPUB, FB2** | боб, шеър, муқова ўзидан олинади (энг яхши натиҷа) |
| **PDF** | сарлавҳа/пойи такрорий саҳифа ва рақам тозаланади, абзац киргизишидан сархат аниқланади. Скан (расм) PDF-га OCR керак. Қадимий ҳарфли PDF-да ҳарфлар бузилиши мумкин (конвертер огоҳлантиради) |
| **TXT** | «БОБИ…» ё КАТТА ҲАРФЛИ сатр = боб |

Қўшимча: `--cover муқова.jpg` (агар китобда муқова бўлмаса), `--slug nomi-lotini` (бир хил slug билан қайта юклаш китобни **навсоз** мекунад, такрор яратмайди), `--out папка`.
`.doc` бўлса, аввал Word'да `.docx` қилиб сақланг.

Қоида: матн **ҳеч гоҳ таҳрир қилинмайди**. Фақат ортиқча фосила тозаланади.

## 2. zip ичидаги шакл
```
book.json   → {id, title, author, category, lang:"tg", cover:"cover.jpg", parts:[{title, chapters:[{id, title, blocks:[...]}]}]}
cover.jpg   (ихтиёрӣ, 700px гача)
```
Блоклар: `["p", матн]` сархат, `["v", [сатрҳо]]` шеър, `["sub", матн]` кичик сарлавҳа, `["s"]` ажратгич «* * *».

## 3. Иловага юклаш
Account → **Идоракунӣ** → **Бастаи китоб (zip)** → **Интихоб** (якчанд zip бирданига мумкин). Агар телефон (масалан Android) zip-ни интихоб нагузорад, zip-ни кушода, ичидан **book.json**-ро алоҳида интихоб кунед: иловада «Бастаи китоб (zip ё book.json)» ҳарду шаклро мехонад (book.json бо муқова нест: муқоваро баъд «Таҳрир» → «Муқова (расм)» бор кунед, муқоваи пештара нигоҳ дошта мешавад). Китоб **пинҳон** юкланади (фақат админ кўради). Тайёр бўлгач, китобни **Таҳрир** → «Барои ҳама намоён» ни белгилаб нашр қилинг.

## 4. APK ва телефонларга қандай етади?
Китоблар Supabase серверида. Иловани (APK, сайт) очганда рўйхат серверданми юкланади. **APK қайта йиғиш керак эмас, ўрнатиш ҳам.** Нашр қилинган китоб ҳамма телефонда иловани кейинги очишда пайдо бўлади.

## Android ва .kitob
Android баъзан zip-ро «кушода» мефиристад (мундариҷаро нишон медиҳад) ва интихоб намегузорад. Барои ҳамин конвертер ҳамон мундариҷаро бо пасванди **`.kitob`** ҳам мемонад. Ба Android/iPhone **`.kitob`**-ро фиристед: интихоб мешавад. Дар барнома «Бастаи китоб (.kitob, zip ё book.json)» ҳамаро мехонад.
