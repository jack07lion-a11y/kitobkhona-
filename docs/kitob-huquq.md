# Китобҳо: манба ва ҳуқуқ (бо ҳар китоб навишта мешавад)

Қоида (Ҷасурбек): ҳар китобе, ки ба Китобхона меояд, пеш аз ворид кардан бо PDF-и тайёр (матн + расмҳо) ва ҶАДВАЛИ ҲУҚУҚ дода мешавад. Майдонҳои ҳуқуқ дар `books`: `rights_status` (public_domain / licensed / pending), `rights_holder`, `source`, `edition`, `translator`, `license_note`. Ҳолати пешфарз: pending.

Асбобҳо: матнро аз скан бо `tesseract` (забони `tgk`) мехонем, матн ҳеҷ гоҳ «тузатма» намешавад (ғайр аз хатои равшани OCR), расмҳоро ҷудо мекунем. Баъд PDF, баъд аз тасдиқи Ҷасурбек китоб(ҳо) ба сервер.

## Қоидаи умумӣ
- Муҳлат: дар Тоҷикистон чун қоида умри муаллиф + тақрибан 70 сол. Санаҳоро бо юрист санҷед.
- Мулки умум будани асл ≠ мулки умум будани тарҷума, таҳрир, расм, нашр.
- Ҳар китобро бо: муаллиф, тарҷумон, нашриёт, сол, ISBN, адади нашр, муҳаррир/рассом, соҳиби ҳуқуқ ва ҳолат нишон диҳед.
