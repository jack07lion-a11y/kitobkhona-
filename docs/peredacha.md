# Китобхона — супоридани лоиҳа ба барномасоз (бе Claude)

Ин ҳуҷҷат барои вақтест, ки Claude (Anthropic) дастрас нест ва лоиҳаро одами дигар ё воситаи дигар давом медиҳад. Онро ҳам Ҷасурбек, ҳам барномасози нав мехонад.

Қоида: **пароллар, калидҳои сервер (`service_role`), рамзи калити APK дар ин ҳуҷҷат ва дар репо навишта намешавад.** Онҳо дар ҷойҳои хавфсиз (қисми 2) нигоҳ дошта мешаванд.

## 1. Ҷавоби кӯтоҳ

- **Оё лоиҳа бе Claude давом карда метавонад? Ҳа.** Код оддӣ аст (JavaScript бе фреймворк, Python, як қисми хурди Java, SQL), ҳамааш дар GitHub, тест ва ҳуҷҷат ҳаст. Ягон қисми махфӣ ё «ҷодуӣ» нест.
- **Кӣ лозим?** Як барномасози веб (JavaScript, HTML, CSS). Барои корҳои APK/Play каме донистани Android (Java) ва барои сервер каме донистани PostgreSQL/Supabase. Дар бисёр ҳолат як одами full-stack кифоя аст.
- **Худамон метавонем?** Қисман. Қисмҳои бе компютер ва бе код: илова кардани китоб, дидани омор, идораи ёрдамчиён, нашри APK бо тугма. Тағйири код компютер лозим дорад (қисми 7).
- **Бузургтарин хавфҳо:** (1) рамзи калити APK (`KS_PASS`) гум шавад; (2) дастрасӣ ба GitHub, Supabase ё Google Play танҳо дар як одам бошад. Дар қисми 8 «чӣ карда мондан лозим» навишта шудааст.

## 3. Лоиҳа чӣ тавр сохта шудааст

```
src/                     сарчашма (ШУМО ИНРО ТАҲРИР МЕКУНЕД)
  features.json          рӯйхати феатурҳо бо тартиби боргирӣ
  shell/                 head, early (сплэш), tail
  features/<ном>/        *.js, *.css, test.cjs (санҷиши феатур)
tools/build.py           src/ -> index.html (як файл), version.json
index.html               НАТИҶАИ СОХТА. Худи онро ҳаргиз таҳрир накунед
apk/                     Android (Java, бе Gradle: build-ci.sh), ks.enc
docs/sql-*.sql           ҳамаи тағйироти база (бо тартиб: docs/pre-launch/SQL-TARTIB.md)
tests/                   run.js (Playwright), crawl.js, run-sql.sh (PostgreSQL), Java-тестҳо
.github/workflows/       test.yml (CI), apk.yml, aab.yml (Play), kalit.yml, parol-check.yml
CLAUDE.md                қоидаҳои лоиҳа (барои ҳар як барномасоз муфид)
docs/arxitektura.md      меъмории код, чӣ тавр феатури нав илова кардан
docs/davom.md            ҳолати лоиҳа ва кори навбатӣ
```

Асосҳо:
- Як саҳифа, JavaScript бе фреймворк. Ҳолат дар объекти `S`, рендер дар `render()`, пайвасти тугмаҳо дар `bind()`. Захира дар localStorage, калид `kitob10`.
- Сайт ва APK як `index.html`-ро истифода мебаранд. APK як «пӯсти» WebView дорад (`apk/src/src/tj/kitobkhona/app/*.java`).
- **Нусхаи Play** (AAB) интерфейсро аз дохили худи AAB мегирад ва худро навсозӣ намекунад (қоидаи Google). Нусхаи GitHub (APK) дар баъзе ҳолатҳо худкор навсозӣ мешавад.
- Серверҳои дигар нест: ҳама сервер Supabase аст (аут, ҷадвалҳо, Storage). Суроғаи Supabase ва калиди ошкор (publishable) дар `src/features/core/20-data.js` навишта шудаанд ва маҳфӣ нестанд.

## 4. Дар компютери худ оғоз кардан

Лозим: `git`, `python3`, `node` (20 ё болотар), барои тест Chromium (Playwright).

```bash
git clone https://github.com/jack07lion-a11y/kitobkhona-.git
cd kitobkhona-
python3 tools/build.py                # index.html месозад
python3 -m http.server 8080           # бикушоед http://localhost:8080
npm i playwright && npx playwright install chromium
node tests/run.js                     # ҳамаи тестҳо (тақрибан 5 дақиқа)
node tests/run.js rating stats        # танҳо феатурҳои алоҳида
python3 tools/tojik_check.py          # санҷиши тоҷикии софи матн
tests/run-sql.sh                      # SQL дар PostgreSQL-и маҳаллӣ (PostgreSQL лозим)
```

## 5. Корҳои оддии ҳаррӯза (рецептҳо)

**Тағйири намуд ё рафтор**
1. Файли дахлдорро дар `src/features/<феатур>/` таҳрир кунед.
2. `python3 tools/build.py`
3. `node tests/run.js <феатур>`
4. Commit: ҳам `src/`, ҳам `index.html`, ҳам `version.json` (CI мувофиқатро месанҷад).
5. Бранч → Pull Request → CI сабз → merge. Сайт худкор навсозӣ мешавад (GitHub Pages).

**Матни нав дар барнома (тарҷума)**
Ҳар матни тоҷикии нав як сатр дар `src/features/i18n/rows.json` лозим дорад: тоҷикӣ, русӣ, ӯзбекӣ (лотинӣ), англисӣ.

**Китоби нав**
Бе код: Word/PDF/EPUB/FB2/TXT-ро бо `python3 tools/kitob_convert.py` ба `.kitob` табдил диҳед (тафсилот `docs/KITOB-PACK.md` ва `docs/kitob-format.md`; ин файл ба ҳар AI-и дигар низ дода мешавад). Баъд дар барнома: Ҳисоб → Идоракунӣ → боргузории китоб. Матни китобро тағйир надиҳед. Барои ҳар китоб як сатр дар `docs/pre-launch/books_rights.csv` (ҳуқуқ).

**Тағйири база (SQL)**
Файли нав `docs/sql-<ном>.sql` ва санҷиши `docs/sql-<ном>-test.sql` нависед, дар `docs/pre-launch/SQL-TARTIB.md` илова кунед. SQL-ро ҳамеша **соҳиби Supabase** дар Supabase → SQL Editor нусха карда Run мекунад. Пеш аз тағйири калон: Supabase → Database → Backups.

**Нашри APK (Android, GitHub)**
Push ба `main` → workflow «APK» ҳамеша релизи «номзад» (`apk-N`) месозад. Корбарон ҳангоми пахши «Нашр кардан» дар Идоракунӣ (танҳо админ) мегиранд. Нахуст дар телефони воқеии Android санҷед.

**Нашр дар Google Play**
Workflow «AAB (Play)» (дастӣ) → артефакти `kitobkhona-play` (файли AAB) → Play Console → Тестлаш → Релиз нав → боргузорӣ. Тафсилот ва ҳолати ҳозира: `docs/play-console.md`. Рақами версия худкор меафзояд. Ҳар релиз аз санҷиши Google мегузарад.

## 5а. Қоидаҳои муҳим

- **Матн тоҷикии софи адабӣ.** Калимаи русӣ ё ӯзбекӣ хато аст. Рӯйхати хатоҳо дар `CLAUDE.md` ва `tools/tojik_check.py`.
- `index.html`-ро дастӣ таҳрир накунед. Ҳамеша `build.py`.
- Китоб ба `index.html` ё APK ворид намешавад: ҳама китоб аз Supabase меояд.
- Ҳуқуқи китоб: ҳамаи китобҳо «мулки ҷамъиятӣ» (қарори Ҷасурбек ва Ҷумъаназар) ё `licensed` бо ном ва манбаъ. Худ аз худ чизе тасдиқ накунед.
- Калид (`*.jks`), парол ва `service_role` ба репо ё чат намеафтад.

## 6. Чизҳое, ки ҳанӯз тафтиш нашудаанд

- APK дар телефони воқеии Android: воридшавӣ бо Google, эслатмаҳо, навсозии худкор, режими суръат (`perf`) дар телефони суст: санҷиши дастӣ лозим.
- Санҷиши Google барои воридшавӣ бо Google (ҳоло «санҷида нашудааст», ҳад 100 корбар).
- Ҳуқуқи китобҳо: ҳоло ҳама «мулки ҷамъиятӣ» бо қарори таъсисгузорон; шояд юрист лозим.
- Рӯйхати пурраи кори кушода: `docs/davom.md`, `CLAUDE.md` (қисми «Нима қолд»).

## 7. Худамон метавонем? (Ҷасурбек, iPhone)

**Бе компютер ва бе код мумкин аст:**
- Китоби нав илова кардан (конвертер лозим, ё ба AI-и дигар `docs/KITOB-PACK.md` диҳед).
- Омор дидан, ёрдамчиён идора кардан, хато ва хабарҳо, «Нашр кардан» барои APK.
- Дар Supabase SQL-и тайёрро нусха карда Run кардан.
- Дар Play Console релизи тайёрро боргузорӣ кардан.

**Компютер лозим аст:** тағйири код, сохтани `index.html` (`build.py`), тест, сохтани AAB (ё бо GitHub Actions бо тугма, сипас файлро аз «Actions → Artifacts» гирифтан).

**Бо AI-и дигар (Codex, Gemini, Copilot, Cursor ва ғайра):**
1. Репоро ба агент диҳед (ё ба компютер клон кунед).
2. Ба агент нависед: «Аввал `AGENTS.md`, `CLAUDE.md`, `docs/peredacha.md` ва `docs/davom.md`-ро бихон».
3. Агент бояд `tools/build.py`, `node tests/run.js` ва `tools/tojik_check.py`-ро иҷро кунад ва Pull Request кушояд. Худи шумо PR-ро merge мекунед.
4. Ҳеҷ гоҳ ба агент калид, парол, `service_role` надиҳед.

Агар кӯмак лозим шавад, беҳтар аст як барномасози воқеӣ тарзи кори AI-ро аз назар гузаронад (қисми 9).

## 8. ҲОЗИР (дар вақти ҳастани Claude) ин корҳоро кунед

Ин сатрҳо қисми муҳимтарин аст. Ҳар як хатарро аз байн мебарад.

1. **`KS_PASS`**: рамз дар **ду ҷои алоҳида** (коғаз дар ҷои бехатар + идоракунандаи рамз ё Google Drive бо рамз) ва дар дасти Ҷумъаназар (як нусха). Бе он APK-и нав имзо намешавад.
2. **Нусхаи репо**: яке ба GitLab ё Codeberg (mirror) ва як нусха дар компютери шумо (`git clone --mirror`). GitHub аз даст равад, лоиҳа мемонад. Нусхаи `apk/ks.enc` дар репо ҳаст.
3. **Нусхаи база**: Supabase → Database → Backups; ва ҳамарӯза/ҳафтаина нусхаи `pg_dump` (рамзи база дар Supabase → Settings → Database). Файли нусха дар Drive, на дар репо.
4. **Play Console**: Ҷумъаназарро ҳамчун корбар илова кунед (Users and permissions → Invite). Танҳо як нафар соҳиб бошад, ҳисоб гум шавад, барнома аз даст меравад.
5. **GitHub ва Supabase**: дар ҳар ду ҷо дуюмин Admin (Ҷумъаназар ё шахси боварӣ). Ҳисоби асосиро бо 2FA (тасдиқи ду қадам) ҳимоя кунед ва рамзҳои барқарорсозиро нигоҳ доред.
6. **Ҷадвали қисми 2**-ро пур кунед (кӣ, куҷо). Рамз ба ҷадвал не.
7. Як бор бо AI-и дигар як тағйири хурдро санҷед (масалан, матни як тугма): оё PR кушода, CI сабз ва merge шуд? Он гоҳ бидонед, ки роҳи эҳтиётӣ кор мекунад.

## 9. Барномасоз ёфтан ва ба ӯ чӣ додан

**Кӣ лозим:** барномасози JavaScript (веб), бо донистани Git ва GitHub. Android ва SQL афзалият аст, аммо шарт нест. Забони кор: тоҷикӣ (матни барнома) ва русӣ/англисӣ (код).

**Дар куҷо ҷустан:** ҷамъиятҳои IT-и Тоҷикистон дар Телеграм, дӯстон ва шиносон, платформаҳои фрилансерӣ (Upwork, Kwork, freelance.ru). Нарх ва шартро бо худи одам мувофиқа кунед.

**Пеш аз ҳама санҷиши хурд (супориш барои номзад):**
> Репоро клон кунед, `python3 tools/build.py` ва `node tests/run.js`-ро иҷро кунед. Дар феатури `rating` матни як тугмаро иваз кунед, тест нависед/навсозӣ кунед, Pull Request кушоед. Ҳамаи санҷишҳо (CI) бояд сабз бошанд.

Агар номзад инро дар 1–2 рӯз кард, ӯ лоиҳаро фаҳмид.

**Матни хабари аввал (нусха кунед):**
> Салом. Китобхона — китобхонаи электронии ройгони тоҷикӣ (сайт, PWA ва Android). Код: GitHub `jack07lion-a11y/kitobkhona-`, JavaScript бе фреймворк, сервер Supabase. Лозим: нигоҳубин ва рушди иловагӣ (тағйири намуд, хатоҳо, китобҳо, нашр). Аввал `docs/peredacha.md`, `CLAUDE.md` ва `docs/davom.md`-ро бихонед. Дастрасӣ барои шумо: GitHub (ҳуқуқи Write), Supabase (корбар бо ҳуқуқи маҳдуд). Калидҳо ва рамзҳоро шумо наменигаред, имзои APK-ро GitHub Actions мекунад.

**Хавфсизлик ҳангоми додани дастрасӣ:**
- GitHub: дар Settings → Collaborators ба ӯ ҳуқуқи **Write** диҳед, на Admin. Ӯ ба `Secrets` дастрасӣ намегирад. **`KS_PASS`-ро ба ӯ надиҳед.** Ӯ push мекунад, CI имзо мекунад.
- Supabase: ӯро ҳамчун узви лоиҳа бо ҳуқуқи камтарин дар Organization илова кунед; SQL-ро шумо Run мекунед ё ӯ дар Supabase бо назорати шумо. `service_role` ва рамзи базаро надиҳед, магар зарурат шавад (дар ин ҳол баъд иваз кунед).
- Play Console: ҳуқуқи «Release manager» (на Admin), агар лозим шавад.
- Бо ӯ шартнома/созишнома (ҳадди ақал хаттӣ дар чат) ва бо Ҷумъаназар маслиҳат кунед. Ҳуқуқи иҷозатномаи код: `LICENSE` (ҳамаи ҳуқуқҳо ҳифз шудаанд).
- Рафт, дастрасии ӯро фавран бардоред ва рамзҳоеро, ки дид, иваз кунед.

## 11. Агар ҳама чиз гум шавад

- Репо: аз нусхаи GitLab/Codeberg ё `git clone --mirror`.
- Сайт: GitHub Pages аз `main` (суроғаи нав дар Settings → Pages).
- База: Supabase Backups; аз нусхаи `pg_dump` тавассути `psql`.
- Калити APK: `openssl enc -d -aes-256-cbc -pbkdf2 -iter 600000 -in apk/ks.enc -out kitobkhona.jks` (рамзи `KS_PASS` лозим).
- Play Console: агар `KS_PASS` гум шавад, дар Play App Signing калити боргузорӣ (upload key) аз нав сабт шуда метавонад (аз Google дархост кунед). Тафсилоти ин ҷараёнро дар `docs/play-console.md` ва ёрдамномаи Google дидан лозим.
