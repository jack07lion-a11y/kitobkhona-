## Сабабҳо ва маҳдудиятҳо (рост)
1. **Supabase-и воқеӣ санҷида нашуд** (қоида: ба production намеравам). SQL дар PG маҳаллӣ бо `auth`/`storage`-и тақлидӣ санҷида шуд. Фарқият имконпазир аст (масалан сутунҳои `auth.users`, `storage.objects`).
2. **APK қурида нашуд**: дар муҳити таҳия Android SDK нест, `android.jar` аз GitHub ва Maven баста буд. Тағйироти Java (`MainActivity`, `Flavor.java`) бо `javac` барои хатои синтаксис санҷида шуд (хатои синтаксис нест; хатоҳои «Android-и номаълум» интизоранд). **Бояд CI ё қурилма санҷад.**
3. **AAB қурида нашуд**: ҳамон сабаб (нет SDK) + `bundletool` боргирӣ шуд (SHA-256 сабт шуд, `aab.yml`), аммо `aapt2 --proto-format` ва `jarsigner` ҳанӯз иҷро нашуданд. Workflow «AAB (Play)» дастӣ иҷро шавад; агар афтад, лог ба ман.
4. **iPhone**: PWA дар Safari воқеӣ санҷида нашуд; Playwright танҳо manifest, иконка, service worker ва офлайнро дар Chromium месанҷад. Safari ба иконкаҳои PNG ва `apple-touch-icon` такя мекунад (ҳастанд).
5. **Тарҷума**: сатрҳои нав (розигӣ, «Ба зудӣ», ҳуқуқ) ба `i18n/rows.json` ҳанӯз илова нашудаанд: бо забони ру/уз/ан онҳо тоҷикӣ мемонанд.
6. **Парчаи ройгон**: китоби Премиум-и баста акнун матнро нагирифта, варақи обунаро нишон медиҳад (3 саҳифаи ройгон нест, зеро матн пурра баста мешавад). Агар парча лозим бошад: файли алоҳидаи «sample» ва ҷадвал/сутуни нав мехоҳад. **Қарор аз шумо.**
7. **Storage-и ятим**: `delete_me` сатрҳои `storage.objects`-ро нест мекунад ва аватарро аз Storage API ҳам мегирад; файлҳои скриншоти `reports` дар S3 мумкин бимонанд. Дар Supabase → Storage санҷед.
8. **Китобҳои нашршуда**: пас аз `sql-mulk.sql` ҳама `pending` мешаванд, аммо нашрӣ мемонанд; ҳуқуқро худатон пур мекунед.
9. **Landing**: корти «Захира дар ҳисоб» ва «Ҳисобро нест кардан» фақат баъд аз `sql-holat/sql-maxfiyat` дар Supabase кор мекунанд. Landing-ро баъд аз SQL нашр кунед.
10. **Дастрасӣ**: `viewport` `user-scalable=no` (калон кардан бо ангушт баста) дар `src/shell/head.html` монд; хонанда андозаи ҳарфро худаш дорад. Тавсия: барои Play/дастрасӣ баъдтар кушоед.
11. **Play-сиёсат**: `updateShell` (HTML-ро аз сайт гирифтан) дар нусхаи `play` хомӯш; нусхаи `direct` онро нигоҳ медорад. Дар сиёсати Play маслиҳати юристӣ набояд аз ман интизор шавед.
