# Google Play «Data safety» — КОРАЛАМА

Бунёдгузорон пеш аз нашр дар Play Console дуруст будани ҳар сатрро тасдиқ мекунанд. Ин ҷадвал аз КОД сохта шудааст (ҳуқуқӣ хулоса нест).

| Маълумот | Ҷамъ мешавад? | Куҷо | Барои чӣ | Қайд |
|---|---|---|---|---|
| Почтаи электронӣ | Ҳа | Supabase (auth) | Дохилшавӣ бо рамз | Брево фиристодани хати рамзро мекунад |
| Ном (беҳамто), ҷинс | Ҳа | Supabase (`profiles`, user_metadata) | Профил | Ҷинс барои қоидаи аватар (духтарон) |
| Сурат/баннер/«дар бораи худ» | Ихтиёрӣ | Supabase Storage `avatars` (оммавӣ) | Профил | Файли аватар бо URL-и оммавӣ хонда мешавад |
| Синну сол (18+/аз 18 хурд), розигӣ, огоҳии волидон | Ҳа | `profiles` | Розигӣ | `save_consent` |
| Омори хондан (сония, китоб, рӯзи фаъол) | Ҳа | `read_stats`, `active_days` | Беҳтар кардани барнома ва рейтинг | Ба корбар вобаста (user_id); дақиқаҳо дар рейтинг ба корбарони дигар кушодаанд |
| Ном, аватар, «дар бораи худ», дақиқаҳо дар рейтинг | Ҳа (хомӯш кардан мумкин) | `leaderboard()` | Рейтинги китобхонҳо | Танҳо воридшудагон, Top 10; Танзимот → «Дар рейтинг нишон дода шавам» |
| Пешравӣ, токчаҳо, хатчӯбҳо | Ҳа | `user_state` | Нигоҳдорӣ ҳангоми аз нав насб | `sync_state` |
| Шиносаи дастгоҳ (тасодуфӣ) | Ҳа | `app_installs` | Шумораи насбҳо | Бе почта ва ном |
| Хатоҳои техникӣ, паём, скриншот | Бо иҷозаи корбар | `error_log`, `reports`, Storage `reports` | Ислоҳи хато | Маълумоти дастгоҳ: намуд, Android, версия |
| Мавқеъ, тамос, файлҳои телефон | Не | — | — | Танҳо расме, ки корбар худ интихоб мекунад |
| Реклама / фурӯши маълумот | Не | — | — | Дар код реклама ё SDK-и таҳлилии тарафи сеюм нест |

## Нест кардан
- Дар барнома: Танзимот → Ҳисобро нест кардан (`delete_me`). Ҳисоб ҳамон дам баста мешавад (`banned_until`, `deleted_at`); маълумот **30 рӯз** мемонад (тиклаш танҳо админ); баъд админ «Тоза кардан»-ро пахш мекунад (`purge_deleted`) ва ҳамаи маълумот нест мешавад. Мӯҳлати 30 рӯз худкор нест: ба админ ёдрас кунед.
- ДИҚҚАТ: файлҳои Storage (аватар, скриншот) аз ҷадвали `storage.objects` нест мешаванд; барои аватар барнома ҳамчунин файлро аз Storage API бармедорад. Дар панели Supabase → Storage санҷед, ки файли ятим намондааст (ба `STATUS.md` нигаред).

## Шифрнокӣ ва интиқол
HTTPS (Supabase). Дар қисмати шифрнокии Play Console «Ҳа, маълумот ҳангоми интиқол шифр мешавад» — тасдиқи бунёдгузорон лозим.

## Чизҳои кушод
- Ҷойгиршавии сервер (Frankfurt, аз `docs/davom.md`) — тасдиқ кунед.
- Мӯҳлати нигоҳдорӣ — муайян нашудааст.
