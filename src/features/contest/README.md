# Озмун (contest)

Саҳифаи «Озмун» ва зерсаҳифаҳои он. Ҳоло дар `10-contest.js` муҳаррири харитаи «доира» (cx*) ҳаст.

Зерсаҳифаҳо (ҷой омода аст, мундариҷа баъдтар):
- `ilm/` — ИФМ
- `furugh/` — Фурӯғ
- `bahs/` — Баҳс

Зерсаҳифаи нав = папкаи нав дар `contest/` + файли `NN-ном.js`-и он дар худи `contest/` (build.py танҳо файлҳои бевоситаи папкаи феатурро мегирад).
Нусхаи зерин: `contest/20-ilm.js`. Санҷиш: `contest/test.cjs`.
